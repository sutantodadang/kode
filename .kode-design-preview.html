Motion rules

  • Streaming lands in word/sentence chunks — no character typewriter effect.
  • ONE moving region maximum. Single spinner instance: · • ● •
  • Unknown duration shows elapsed time (● cargo test 08.4s), never fake progress.
  • New Z/I evidence steps dim → normal over three frames; settled rows never move again.
  • Diffs, provenance, verification results, and user input never animate.
  • reduced_motion config kills spinner + pulse entirely.

Anti-slop (non-negotiable)

  • No gradients · no emoji in core UI · no chat bubbles · no box around every section
  • No permanent file-tree sidebar · no card grids · no spinner beside streaming prose
  • No color without semantic meaning · no fake thinking animation
  • No knowledge display without real zindeks/ingat data behind it
