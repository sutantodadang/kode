# Agent instructions

Project conventions, build/test commands, and the engine architecture are in
[`CLAUDE.md`](CLAUDE.md) and [`CONTRIBUTING.md`](CONTRIBUTING.md). Read them first.

## Design System

Always read `DESIGN.md` before making any visual or UI decisions.
All terminal hierarchy, colors, spacing, glyphs, motion, and interaction states are defined there.
Do not deviate without explicit user approval.
In QA mode, flag code that does not match `DESIGN.md`.
